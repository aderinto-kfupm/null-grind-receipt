How the receipt works

Every task goes through the 3-question test: does it happen every week, does it start the same way every time, and would you catch a mistake in under a minute?

Machine
Passes all three. Counts the time saved, minus 1 min per run to check it.
Delete
Nobody would notice if you stopped. All of its time counts.
Pipe it
AI drafts, you check. Shown, but not in the total.
Human
Needs you (or happens too rarely). Not counted.

Per year = per week × 52 · Work weeks = ÷ 40 h · Kill first = the fastest payback on setup time.
